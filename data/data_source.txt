HOW TO REPRODUCE THE DOWNLOAD
-----------------------------

    mkdir -p data && cd data
    curl -L -o online+retail.zip "https://archive.ics.uci.edu/static/public/352/online+retail.zip"
    unzip online+retail.zip

The extracted file must be named exactly "Online Retail.xlsx" and placed in the data/
directory. The notebook locates it automatically.

VERIFY THE FILE BEFORE ANALYSIS
-------------------------------

    sha256sum "Online Retail.xlsx"

Expected output:
    43465a06f2ccf7c8b5bd2892bc7defb52f97487934fe93b16ae4c3936424676d  Online Retail.xlsx

If the fingerprint does not match, do not run the analysis: the file may be corrupted or
modified. Download it again from the official URL above.

WHY THE RAW FILE IS NOT COMMITTED
---------------------------------

The raw workbook is 23 MB. Committing it would bloat the repository and is unnecessary
because the file is publicly available from the official source with a stable DOI.
The SHA-256 fingerprint above allows any reader to verify that they are analysing the
same file. All results in this repository were produced from the file with this exact
fingerprint.
